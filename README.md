## 使用方式

1. **開新場次。** 提供賽事名稱或聯盟、比賽日期及對戰隊伍，例如「中職｜YYYY/MM/DD｜樂天桃猿 vs 中信兄弟」。若同日同隊有多場比賽，再提供開賽時間或場次編號。助理確認場次後會執行完整匯入，查證與登錄來源，並將新資料補入既有賽事、球員與投打對戰條目。
2. **取得賽前成品。** 場次匯入完成後，助理會依 Wiki 資料產出 Markdown 備稿、逐頁講稿及 16:9 離線 HTML，並同步加到首頁的目前場次卡。指定另一場比賽後，上一場會移入歷史頁。你也可以說「切回 11/12 台日戰」，將它重新顯示在首頁。兩隊完整名單依背號放在簡報附錄。
3. **回報場上事件。** 例如「五局上半，郭天信在右外野完成接殺」。助理會先給可直接念的口播，再把球員、事件、局數、口播和背景來源記入該場 notes。若你只說「郭天信接殺了」，會先暫記「局數待補」，等你回覆「五上」後更新同一筆。
4. **產出賽後回顧。** 說「這場比賽已結束，請做賽後回顧」。助理會依比賽順序整理 notes 裡的精采片段，另存逐頁 Markdown 和離線 HTML，並將回顧 HTML 加到同一張賽事卡。若只確認比賽結束，先更新該卡的賽事狀態。你也可以指定必收的片段。

## 資料夾與維護

| 位置 | 用途 |
| --- | --- |
| `raw/` | 來源登錄、取用條件與可保存的原始資料 |
| `wiki/` | 賽事、球員卡、投打對戰及數據口徑 |
| `notes/` | 賽前備稿、球員名單及直播精采紀錄 |
| `slides/` | 逐頁畫面文字與講稿提示 |
| `presentation/` | 可離線播放的 HTML 簡報 |
| `assets/` | 原創球衣背號圖示 |
| `templates/` | 新增球員卡的模板 |

正式打序、實際出場及數據以各頁的查核狀態為準。口播用自己的話整理可核實的事實，來源連結供團隊備查。批次擷取、轉載圖文或使用賽事影像前，請查對應的使用條件。 [來源與使用條件](raw/sources.md)

維護流程見 [AGENTS.md](AGENTS.md)，歷次匯入與更新見 [log.md](log.md)。
